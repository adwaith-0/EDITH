# Mapped charger snapshot for the local MVP

`charging-directory-snapshot.json` contains 315 actual OpenStreetMap records returned by a successful Overpass query on 23 October 2026. The snapshot includes its query time, bounding rectangle, attribution, and per-record OpenStreetMap source links. It is a partial mapped directory, not a list of verified working or bookable chargers.

Data: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Unknown connector/power values remain unknown. Do not infer equipment from station names.

The local MVP labels cached results and offers live refresh. Newly generated route gap points are separate, explicitly synthetic simulation records and are not included in this source snapshot. A production directory needs a maintained data ingestion process and operator availability/reservation integrations.
